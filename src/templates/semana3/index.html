Sistema de Gestión de Matrículas y Pensiones

Módulo de la Semana 3 con persistencia en base de datos (Django ORM + SQLite).

Catálogos (entidades independientes)

  • Niveles educativos
  • Años lectivos
  • Tipos de descuento
  • Métodos de pago
  • Apoderados

Entidades relacionadas (ForeignKey)

  • Grados → Nivel educativo
  • Estudiantes → Apoderado
  • Matrículas → Estudiante, Año lectivo, Grado
  • Pensiones → Matrícula, Tipo de descuento
  • Pagos → Pensión, Método de pago
